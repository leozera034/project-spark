PROMPT DE INTEGRAÇÃO — COMANDIVA

Você vai atuar no repositório do Comandiva e deve apenas organizar e vincular os assets temáticos do wizard de pedido do cliente, sem alterar desnecessariamente o layout.

OBJETIVO
Garantir que cada tipo de loja use automaticamente:
1) fundo mobile correto no wizard do cliente;
2) fundo desktop correto no wizard do cliente;
3) logo correta para o mesmo tema;
4) fallback neutro para "outros" e para tipos não reconhecidos.

PASTAS DOS ARQUIVOS
Use esta estrutura como fonte de verdade:
- wizard/mobile/<tema>.png
- wizard/desktop/<tema>.png
- logos/<tema>.png

REGRAS DE INTEGRAÇÃO
1. Preserve os códigos de tema já usados no projeto:
   pizzaria, hamburgueria, acai, sorveteria, restaurante, lanchonete, pastelaria, adega, mercado, outros

2. Crie ou ajuste um resolvedor central para retornar:
   - getWizardMobileBackground(segment)
   - getWizardDesktopBackground(segment)
   - getThemeLogo(segment)

3. O resolvedor deve aceitar aliases e normalizar para os códigos acima:
   - açaí → acai
   - hamburguer / hamburgeria → hamburgueria
   - marmitaria → restaurante
   - bebidas → adega
   - padaria / conveniência / conveniencia → mercado
   - outro → outros

4. Se o segmento vier no formato interno do onboarding, também normalize:
   - __profile__:pizzaria → pizzaria
   - __profile__:hamburgueria → hamburgueria
   - __profile__:acai → acai
   - __profile__:sorveteria → sorveteria
   - __profile__:restaurante → restaurante
   - __profile__:lanchonete → lanchonete
   - __profile__:pastelaria → pastelaria
   - __profile__:adega → adega
   - __profile__:mercado → mercado
   - __other__:qualquer-coisa → outros

5. No componente do wizard do cliente:
   - em telas mobile, use o fundo mobile;
   - em telas desktop, use o fundo desktop;
   - use a logo do mesmo tema;
   - garanta boa legibilidade do texto por cima do fundo claro;
   - não aplique sobreposição pesada que apague a arte.

6. Se o tema não existir, use:
   - fundo mobile: wizard/mobile/outros.png
   - fundo desktop: wizard/desktop/outros.png
   - logo: logos/outros.png

IMPLEMENTAÇÃO ESPERADA
- Centralizar o mapeamento em um único arquivo.
- Evitar strings soltas espalhadas.
- Manter consistência entre onboarding, loja e link público do cliente.
- Não alterar temas corretos já existentes.
- Não usar fundo de comida errada em categoria errada.
