# Regras do Contador de Entregas

## Estados que CONTAM (1 unidade)
- Entregue (finalizado com sucesso)

## Estados que NÃO CONTAM (0 unidades)
- Atribuído / Aceito
- Chegada à loja
- Coletado / Em rota
- Ocorrência aberta ou resolvida (sem conclusão)
- Cancelado / Recusado
- Retirada (mesmo que concluída)
- Tentativas frustradas
